# ブロック防衛線

ブロックでできた島で拠点コアを守る、ブラウザで遊ぶFPSです。

- **ひとりで遊ぶ**：ロボット軍団からコアを守る
- **みんなで遊ぶ（協力プレイ）**：全員で同じ敵と戦い、ひとつの拠点を守る
- **みんなで遊ぶ（対戦プレイ）**：赤と青の2チームで、相手のコアを壊し合う

同じWi-Fiにつながった端末どうしで遊べます。

## フォルダの構成

```
block-defense/
├─ client/                 ブラウザで動く画面
│  ├─ index.html           画面の骨組み（HTML）だけ
│  ├─ css/style.css        見た目
│  └─ js/
│     ├─ main.js           入口。準備をしてメインループを回す
│     ├─ core/             決まった値（config）・小さな道具（util）・共有の状態（state）
│     ├─ world/            ブロックの世界のデータ・一人用の地形づくり・視線の当たり判定
│     ├─ render/           3D表示（シーン・模様・ブロック・キャラクター・コア・演出）
│     ├─ audio/            効果音
│     ├─ input/            パソコン（controls）とタッチ（touch）の操作
│     ├─ player/           自分の体の動き（player）と行動（actions：撃つ・置く・こわす）
│     ├─ game/             一人用の進行（solo）と敵（soloEnemies）、始まりと終わり（session）
│     ├─ net/              サーバーとの接続（connection）・状態の反映（sync）・出来事の演出（events）
│     ├─ ui/               ゲーム中の表示（hud）・待合室（lobby）・結果（results）
│     └─ debug.js          自動テスト用（?debug を付けたときだけ読み込む）
├─ server/                 ゲームサーバー（Python）
│  ├─ __main__.py          起動の入口（python -m server）
│  ├─ config.py            調整用の値と決まった値
│  ├─ util.py              小さな道具
│  ├─ world.py             ブロックの世界（地形づくり・視線の当たり判定）
│  ├─ entities.py          プレイヤーと敵ロボット
│  ├─ lobby.py             待合室のルール
│  ├─ coop.py              協力プレイのルール（ウェーブ・敵の動き）
│  ├─ pvp.py               対戦プレイのルール（ラグ補償つきの命中判定・コア攻撃）
│  ├─ game.py              ゲーム本体（3つのルールを組み合わせ、共通処理を持つ）
│  └─ network.py           通信（画面の配信・WebSocket・計算と配信のくり返し）
├─ tests/                  自動テスト（サーバーの判定を確かめる）
├─ requirements.txt        動かすのに必要なライブラリ
└─ requirements-dev.txt    テストに必要なライブラリ
```

### どこを直せばいいか

| やりたいこと | 直すファイル |
|---|---|
| 難しさ・ルールの数値を変える | `server/config.py`（一人用は `client/js/core/config.js` と `client/js/game/solo.js`） |
| 敵ロボットの動きを変える | `server/coop.py`（一人用は `client/js/game/soloEnemies.js`） |
| 対戦のルールを変える | `server/pvp.py` |
| 待合室の条件を変える | `server/lobby.py`、表示は `client/js/ui/lobby.js` |
| 地形を変える | `server/world.py` の `generate`（一人用は `client/js/world/generate.js`） |
| 画面の表示を変える | `client/js/ui/` と `client/css/style.css` |
| 見た目（キャラクター・ブロックの模様） | `client/js/render/models.js`・`textures.js` |
| 操作を変える | `client/js/input/` |
| 新しい通信メッセージを足す | サーバーは `server/network.py` の `HANDLERS` と `game.py`、画面は `client/js/net/` |

**注意**：ワールドの大きさ・ブロックの番号・体の大きさは、`server/config.py` と `client/js/core/config.js` の両方に書いてあります。変えるときは両方そろえてください。

## 起動のしかた

Python 3.10 以上が必要です。**`block-defense` フォルダの中で**次を実行します。

### Windows（PowerShell）

```powershell
cd block-defense
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m server
```

### Mac

```bash
cd block-defense
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m server
```

2回目からは、`activate` と `python -m server` だけで起動できます。ポート番号を変えたいときは `python -m server 8080` のように付けます。

1. サーバーを起動したPCでは `http://localhost:8000` を開きます
2. 他の端末では、起動時に表示された `http://192.168.x.x:8000` を開きます
3. 「ひとりで遊ぶ」か、なまえを入れて「みんなで遊ぶ」を押します

止めるときは、サーバーの画面で `Ctrl + C` を押します。

> 以前の版と違い、`index.html` を直接ダブルクリックしても動きません（ブラウザの決まりで、分割したファイルの読み込みにはサーバーが必要なため）。一人用で遊ぶときもサーバーを起動して `http://localhost:8000` を開いてください。

## 自動テスト

サーバーの判定（命中・ヘッドショット・ラグ補償・ブロックの置き壊し・勝敗・待合室の条件・通信の受け答え）を自動で確かめます。数値やルールを変えたあとに実行すると、壊れていないかすぐに分かります。

```bash
pip install -r requirements-dev.txt
python -m pytest
```

すべて `passed` になれば大丈夫です。

画面側をブラウザの自動操作で確かめるときは、アドレスの最後に `?debug` を付けて開くと、中の状態を外から読めるようになります（`client/js/debug.js`）。

## 遊び方とルール

### 操作

| | パソコン | タブレット・スマホ |
|---|---|---|
| 移動 | WASD（Shiftで速く） | 左下のスティック |
| 視点 | マウス | 画面の右側をなぞる |
| 撃つ | 左クリック（長押しで連射） | 撃つボタン |
| 板を置く／こわす | 右クリック ／ F | 置く／こわすボタン |
| ジャンプ | スペース | ジャンプボタン |
| 準備時間を終わらせる | N | 「すぐ始める」ボタン |
| 一時停止／音を消す | Esc ／ M | ― |

### 待合室

- 「協力プレイ」「対戦プレイ」を選び、誰かが「ゲーム開始」を押すと全員そろって始まります。
- 対戦では赤・青に自動で振り分けます（「チームを移る」で入れ替え可）。赤と青に1人以上ずつ必要です。
- 試合が終わると結果が出て、12秒後に待合室へ戻ります。途中で入った人はそのまま参加します。

### 協力プレイ

- 準備時間のあとウェーブが始まります。木の板はチーム共有で、人数が多いほど敵も増えます。
- やられると4秒後に復活します。拠点コアが壊されたら終わりです。

### 対戦プレイ

- 北に赤、南に青の拠点があります。**相手のコアを撃って壊したら勝ち**です。8分たったら、コアの残りが多いチームの勝ちです。
- 最初の20秒は準備時間で、撃てません（Nキーで3秒後に早められます）。
- 仲間には当たりません。頭に当たるとダメージ1.5倍。相手を倒すとチームの板が3枚増えます。
- 相手チームの板は撃って壊し（4発）、自分たちの板は F で回収します。

## しくみ（サーバー権威）

ゲームの「正解」はサーバーだけが持っています。端末は見た目を出し、お願いを送るだけです。

```
端末                                  サーバー（1秒に20回計算）
自分の移動 ──── state（位置・向き）──→ 位置を記録（ラグ補償用に約2秒分）
撃つ ────────── shoot（視線）─────→ 地形・敵・相手プレイヤー・コアに当たるか判定
置く・こわす ── place / break ────→ 距離・重なり・板の数・持ち主を確認
待合室の操作 ── mode / team / start → モード・チーム・開始
                                      敵を動かす・ウェーブ・勝敗
      ←──────── snap（全員・敵・敵の弾・コア・出来事）──
      ←──────── ping（2秒ごと）→ pong で往復時間を測る
```

- **撃った瞬間の光線は、自分の画面にだけ先に出します。** 命中したかどうかはサーバーの判定に従います。
- **ラグ補償**：サーバーは撃った人の往復時間を測っておき、その人の画面に見えていた時点まで相手の位置をさかのぼって当たり判定をします（最大0.3秒）。
- **ズル防止**：連射の速さ、撃った位置、ブロックを置く距離、届いた数値の範囲を、すべてサーバーで確認しています。
- **自分の移動だけは端末で計算**しています。インターネットで知らない人と遊ぶなら、ここもサーバーで確認する必要があります。

### 通信の取り決め

| 向き | t | 中身 |
|---|---|---|
| 端末 → サーバー | `join` | `name`（接続直後に1回） |
| 端末 → サーバー | `state` | `x`, `y`, `z`, `yaw`, `pitch`（1秒に20回） |
| 端末 → サーバー | `shoot` | 撃った位置 `ox`,`oy`,`oz` と向き `dx`,`dy`,`dz` |
| 端末 → サーバー | `place` / `break` | ブロックの座標 `x`,`y`,`z` |
| 端末 → サーバー | `skip` | 準備時間を終わらせる |
| 端末 → サーバー | `mode` / `team` / `start` | 待合室での選択（`coop`・`pvp`、`red`・`blue`） |
| 端末 → サーバー | `pong` | `ping` に入っていた `s` をそのまま返す |
| サーバー → 端末 | `welcome` | 自分の `id`, `color`, `name` |
| サーバー → 端末 | `world` | 地形データとコアの位置（参加時と、試合の開始時） |
| サーバー → 全員 | `snap` | `game`（段階・モード・コア・板・残り時間など）, `players`, `enemies`, `shots`, `e`（出来事の一覧） |
| サーバー → 全員 | `ping` | 往復時間を測るための時刻 `s` |
| サーバー → 全員 | `info` | 参加・退出のお知らせ |

`game.phase` は `lobby`（待合室）、`break`・`fight`（協力）、`prep`・`pvp`（対戦）、`over`（結果）のどれかです。

`snap` の `e` に入る出来事：`shot`, `hit`, `kill`（敵）, `phit`, `pkill`（プレイヤー）, `corehit`, `core`, `block`, `plank`, `hurt`, `eshot`, `respawn`, `wave`, `clear`, `fight`, `start`, `deny`, `over`

## つながらないとき

- **他の端末から開けない**：いちばん多い原因はファイアウォールです。Windowsで初回起動時に「アクセスを許可しますか」と出たら「プライベートネットワーク」にチェックして許可してください。
- **同じWi-Fiか確認**：ゲスト用Wi-Fiや、端末どうしの通信を禁止しているWi-Fi（施設や会社のWi-Fiに多い）ではつながりません。
- **IPアドレスが違う**：Windowsなら `ipconfig`、Macなら「システム設定 → ネットワーク」で「192.168.」や「10.」で始まる番号を確認します。
- **画面が真っ白**：描画ライブラリ（Three.js）をインターネットから読み込んでいます。**開いている端末**がインターネットにつながっている必要があります。
- **`No module named server` と出る**：`block-defense` フォルダの中で実行しているか確認してください。

## 今後の課題

- **一人用の処理が画面側とサーバー側の2か所にある**：敵の動きや地形づくりを直すときは両方そろえる必要があります。一人用もサーバーにつないで遊ぶ形（「1人だけの協力プレイ」）にそろえると、1か所にまとめられます。
- **インターネット越しに遊ぶ**：クラウドのサーバーに置き、HTTPS（`wss://`）にする。知らない人と遊ぶなら移動もサーバーで確認する。
